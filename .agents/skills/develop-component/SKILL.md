---
name: develop-component
description: "Create or update a shared UI component."
---

Inspect existing components and tokens. Define supported variants and interaction states. Reuse accessible primitives, add relevant stories and tests, and check theme and keyboard behavior.

For the active Fibli design milestone, inspect the supplied demo source and docs/design/HANDOFF.md first. Map the real geometry, tokens, icons, material role, states and motion. Document intentional deviations. Build the actual shared component and isolated Storybook example, not a feature screen. Verify keyboard semantics and visual evidence; do not claim approval from compilation alone.
